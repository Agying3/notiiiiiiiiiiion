## 二、核心证据：前端 CONFIG 里的 AI 额度表

`captures/js/2888-f33f695a245e29db.js`（注册页直接加载的 bundle，19KB）里有完整的 `promotions.aiCredits` 配置，原文结构：

```js
promotions: {
  aiCredits: {
    writer: {
      baseGrant:                       { singlePlayerAmount: 50, multiplayerAmount: 50, unit: "credits" },
      userGrant:                       { singlePlayerAmount: 50, multiplayerAmount: 50, unit: "credits" },
      grant032023:                     { singlePlayerAmount: 0,  multiplayerAmount: 0,  unit: "credits", waitMs: 6048e5 },
      studentGrant:                    { singlePlayerAmount: 0,  multiplayerAmount: 0,  unit: "credits" },
      studentGitHubGrant:              { singlePlayerAmount: 0,  multiplayerAmount: 0,  unit: "credits" },
      september2026CreditRefreshGrant: { singlePlayerAmount: 50, multiplayerAmount: 50, unit: "credits", limit: 300 },
      maxAllowance:                    { free: 500, paid: 2500 }
    },
    qna: { /* 与 writer 完全同构，同样的 50/50/500/2500 和 7 天 waitMs */ }
  }
}
```

读懂它需要知道：

- **`writer` 和 `qna` 是两套独立额度**：writer≈AI 写作/编辑块，qna≈问答/Agent 对话。**两边都各给 50 + 50 = 100 credits**
- **`baseGrant` + `userGrant` 是首次发放**：注册后各发 50，合计 **100 credits / 每套**
- **`6048e5` = 604,800,000 ms = 7 天**，对应 `grant032023` 与刷新 grant 的冷却
- **`september2026CreditRefreshGrant` 带 `limit: 300`**：说明刷新不是无限的，累计最多补到 300
- **`maxAllowance` 是余额天花板**：免费 500、付费 2500 —— 这是"攒额度"的上限，不是单次发放量

换算：`$10 / 1,000 credits` → 免费用户一次性 200 credits ≈ **$2 的 AI 用量**；天花板 500 credits ≈ **$5**。

## 三、社区检索：这轮没拿到，原因很明确

试过的通道与结果（全部留痕在 `captures/community/`）：

| 通道 | 结果 |
| --- | --- |
| `www.reddit.com/r/Notion/search.json` | `Connection reset` ×20（换了 20 条代理） |
| `old.reddit.com` | 域名解析到非公网 IP（被代理拦） |
| redlib 镜像（catsarch / safereddit / perennialte / opnxng / privacyredirect） | 全部 RST 或超时 |
| Playwright 打开 reddit 搜索页 | `ERR_CONNECTION_RESET` ×6 |
| `html.duckduckgo.com/html/` | RST ×3 |
| Hacker News Algolia API | **200，可用**，但命中的都是泛 AI 讨论，没有 Notion 额度实测 |
| Bing（普通 + RSS + site: 定向 + 引号精确） | 200，但结果被 Notion 官网/App Store 占满，**没有任何 Reddit/论坛结果** |
| `community.notion.so`（官方论坛 Discourse） | `CONNECT tunnel failed`（代理连不上该域） |
| SearXNG 公共实例 | 200 但返回的是 JS 壳，解析不到结果 |

**判断**：不是"社区没讨论"，而是**当前出口 IP 段被 Reddit/DDG 整体封锁**。HN 能通说明代理本身没问题，是这几个站点按 IP 段拒绝。

## 四、能不能拿个号实测？

### 可以，但有一个前提和一个坑

**前提：需要一个能过 hCaptcha 的号**

- 注册卡在 hCaptcha invisible（上一轮结论），sitekey 已确认：`<uuid>`
- 另外发现：**Business trial 用的是另一个 sitekey** `<uuid>`（同一份 CONFIG 里）
- 刚才又验证了**登录页也需要同一套 hCaptcha**（`login-page.png`，页面渲染出来了但表单未 hydrate，v3 只跑了 getAppConfig + ping）

**坑：现有的 37 个 Hotmail/Outlook 号可能登不进去**

- 这批号带的是 `M.C510_BL2.0.U.MsaArtifacts...` 格式的 Microsoft OAuth artifact（refresh token 类），不是密码
- Notion 走 Microsoft 登录是 OAuth 跳转，能免掉 hCaptcha，**但需要 MSA token 仍然有效**（文件里有 `2026-07-08` 的时间戳，已经 3 个多月）

### 建议的实测方案（30 分钟，可分两次观察）

**第一次（T0，现在）**

1. 用 1 个可用的 MSA 走 Microsoft OAuth 登录 Notion（或注册新号过 hCaptcha）
2. 进 workpsace 后**先不要做任何 AI 操作**，抓一次额度基线：
   - `POST /api/v3/getAiUsage`（接口名待确认，用 404/400 指纹法探）
   - 或直接读 `window.CONFIG` + 前端 store 里的 credit 余额
3. 连续发 **N 次**最小 AI 请求（比如 20 次单句问答），每次记录返回的 credit 消耗
4. 得出：**1 credit 对应多少 token / 一次问答扣多少**

**第二次（T0 + 24h，明天）**

5. 同一账号再抓一次余额 → 判断是否日刷
6. **T0 + 7 天**（2026-10-24）再抓一次 → 验证 `waitMs: 604800000` 的 7 天刷新

**第三次（可选，验证上限）**

7. 把 writer 额度烧到 500，看是否真的封顶（`maxAllowance.free = 500`）
