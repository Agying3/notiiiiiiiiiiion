> 更正时间：2026-10-18 00:55
> 上一份文档（05）里写的「30 天 Business 试用」是**引用了旧的基础 campaign**，结论要改。

---

## 一、你说得对，14 天是当前默认

我把整张 campaign 表按「定义」和「当前在推的分组」两种方式分别数了一遍，差异很明显：

### 全表定义（含所有历史/内部/渠道活动）

| 天数 | 条数 | 说明 |
|---|---|---|
| 4d | 1 | hackathon |
| **14d** | **30** | ← 当前主力 |
| 30d | 33 | 老基础 campaign + plus 系 + 各种 1m 变体 |
| 45d | 1 | `dev_only_45d_reverse`（仅开发环境） |
| 90d | 4 | 创业公司 3 个月 |
| 180d | 5 | 创业公司 6 个月 |
| 365d | 5 | 创业公司 12 个月 + creator |

### 当前在推的那一波：`september_2026` 家族

这是**唯一一个带月份标记的家族**，说明是最近上线/正在跑的活动：

```

14d  september_2026_business_cc_14d               ← 要绑卡

14d  september_2026_auto_stacked_business_trial_14d
30d  september_2026_auto_stacked_business_trial_1m
```

**关键发现：`september_2026` 家族里，reverse 类只有 14 天版。**

我专门验证过：

```
september_2026_business_reverse_1m   ← 存在？False
```

**不存在。** 30 天的那两条（`*_stacked_*_1m`）全是 `stacked`，是给**已经在付 Plus/Business 的人**叠加用的，纯新号拿不到。

## 二、所以 30 天是怎么来的？

`business_reverse`（无后缀）确实是 30 天：

```js
{type:"trial", campaign:"business_reverse", duration:{days:30}, subscriptionTier:"business"}
```

但这是**基础/兜底 campaign**，没被 `september_2026` 那波覆盖到才会用。而 `994234` 模块里的 `y` 分组（reverse 家族判定表）长这样：

```js
y:["business_reverse",                    // 30d
   "business_reverse_14d",                // 14d
   "business_reverse_30_perf_marketing",  // 30d
   "mwn_business_reverse_14d",            // 14d
   "custom_agents_business_reverse_1m",   // 30d
   "custom_agents_business_reverse_14d",  // 14d
   "workers_business_reverse_14d",        // 14d
   "september_2026_business_reverse_14d", // 14d ← 当前
   ...]
```

**14 天的条目数是 30 天的两倍多**。而且带 `perf_marketing` 后缀的那几条（30d）是投流专用，普通注册碰不到。

## 三、修正后的结论

| 说法 | 上一版（错） | 修正后（对） |
|---|---|---|
| 新号默认试用 | 30 天 | **14 天** |
| 30 天怎么拿 | 默认 | 只走 `perfmark` / `business_reverse_30_perf_marketing`（投流渠道）或 `business_reverse`（兜底，可能被 A/B 覆盖） |
| 90/180/365 天 | 没提 | 只有创业公司计划（`*_startup_business`），要申请，普通号没有 |
| 教育版 | 免费 Plus | 不变，还是免费 Plus，没有试用 |

## 五、`business_cc_14d_block_limit` 这条很有意思

```
campaign:"business_cc_14d_block_limit", duration:{days:14}
```

名字里带 `block_limit`，配合之前查到的 callout ID `business_block_limit_trial_announcement_2`，可以确定：

**免费 workspace 撞到 1000 block 上限时，Notion 会用「14 天 Business 试用」当转化钩子。**

这是目前最容易触发的试用入口——不需要等首页弹窗，写到 1000 block 它自己会来找你。而且是 `cc` 系列，要绑卡。
